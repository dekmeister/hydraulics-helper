Gauge system

One parameterised component. Face, bezel and scale are static per dial type; needle, wake and plate are the only parts that change at runtime.

Anatomy — discharge gauge, 1 050 kPa

2.2

One component

gauge({
  scale:  [{ v: [0, 1600], a: [-135, 135] }],
  major:  200,   minor: 50,
  label:  v => v / 100,
  zones:  [{ v: [1200, 1400], tone: 'caution' },
           { v: [1400, 1600], tone: 'alarm' }],
  units:  'kPa ×100',
  plate:  'DISCHARGE',   tag: null,
  value:  1050,
  wake:   { lo: 980, hi: 1110 },
  target: 700
})

Angle = a0 + (v − v0)·(a1 − a0)/(v1 − v0) within a segment. A compound gauge is simply two segments. Ticks are one rotate(θ) line template; zones and the wake are dashed circles rotated to their start angle, so the markup needs no trigonometry.
